# Data

`hr-attrition.csv` — the IBM HR Analytics Employee Attrition sample dataset (n=1,470, 35 columns, target `Attrition` Yes/No).

- Source: IBM's public mirror at https://github.com/IBM/employee-attrition-aif360 (`data/emp_attrition.csv`), identical to the Kaggle release `pavansubhasht/ibm-hr-analytics-attrition-dataset` (`WA_Fn-UseC_-HR-Employee-Attrition.csv`).
- This is **fictional/synthetic** sample data created by IBM data scientists. Findings in this repo demonstrate method, not industry truth.
- Committed to the repo for reproducibility; it is small (~220 KB) and openly distributed.

`train-test-split.csv` — generated by `03-model-R.Rmd` (seed 42, stratified 80/20 on Attrition, keyed on `EmployeeNumber`). Both the R and Python models read this file so their test-set comparison is honest. Do not regenerate casually; committed so results are reproducible.
